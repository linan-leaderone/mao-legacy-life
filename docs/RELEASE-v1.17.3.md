# 1.17.3：返回内容整理与调用次数

本版处理服务已经返回并计费、客户端仍提示文字格式不完整的情况。三种适配器共用本地解析与恢复流程，每次生成只发送一个请求，不因格式或文风问题自动发出第二次调用。源码版本1.17.3，Android versionCode 22，连接配置 `providerRevision` 保持9。安装包及线上发布状态由 [验证记录](VERIFICATION.md) 和 [iOS验证记录](IOS-VERIFICATION.md) 单独确认。

## 读取已收到的内容

`src/narrative-response.js`识别完整JSON对象及常见外围包装，包括代码围栏、前后说明、BOM、标准双重编码和完整前置think/thinking块。字符串实际换行、制表符及合法值后的尾逗号可以在本地无损整理，无需请求服务。同一对象重复出现可以去重，多份不同对象仍拒绝。

解析不执行代码，不补齐截断字符串、括号或剧情，不把裸散文当作有效结果；根数组、标量、危险属性名和超限文本也不接受。同一对象的重名字段一律拒绝，包含Unicode转义后同名的字段。读取成功后仍使用原来的字段、时间、人物、文风及行动结果校验，只有合格结果才提交一次原行动。

ShiWuYan将完整原system规则、输入资料与末尾JSON要求放在同一user消息中，降低转发转换遗漏system字段的影响。DeepSeek原JSON mode与Gemini JSON MIME设置保留，原有世界规则和行动上下文不删减。

## 本人决定是否追加调用

格式或语义校验失败时，完整且不超过256KiB的原文、原prompt和有限元数据只暂存在当前页面内存。恢复草稿不写入存档、本机持久存储或本站服务器；主动整理时才把相应内容发送给当前选中的模型服务。旧版自动 `PROSE_REPAIR` 调用取消，历史文档中的自动修订说明由本版规则覆盖。

原人生和安排未改变时，可以点击“整理已收到的内容”。此操作会额外调用一次服务，沿用原始提示、已结算事实及失败原文，不重新选择月份或抽取行动结果。能够解析的原稿会锁定地点、人物更新、经济记录、公共事件、关系更新及正文可识别的收支金额/方向；整理改动这些字段时继续保留原稿，不提交月份。无法解析的原稿仍按原输入校验，不能保证识别所有自由文本事实。整理断线或取消保留草稿；刷新或关闭页面会丢失草稿，人生存档仍停留在原月。

供应商标记截断或block的回复不提供整理，也不会在本地强行补出结尾。可以主动下载诊断，或明确选择重新生成；重新生成同样会再次调用服务。普通生成和每次明确发起的整理请求各有180秒上限，模型目录查询仍为15秒。同源兼容转发、取消处理、三组默认连接与原生HTTP桥沿用1.17.2。

诊断文件仅在本人点击下载时生成，包含脱敏响应正文和白名单元数据，不包含prompt、action、state、key、请求头或完整请求地址。普通错误提示不直接显示原文。

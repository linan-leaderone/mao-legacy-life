# v1.12 全球行政地图资料

本版使用现实行政区划。世界地图含 258 个国家、属地及来源单列地区的轮廓；这个数字不是主权国家数量。目录包含 55,588 个有真实几何的单位，203 个国家或地区有地方行政层，55 个保留国家/地区轮廓。没有取得的层级在 `public/maps/manifest.json` 的 `coverage` 中逐项说明，不以网格、随机多边形或 MOD 州块冒充县界。

地图按国家和行政层级拆成 384 个几何文件，总计 61,677,629 字节。单文件最大约 4.55 MB。运行索引 15,303,103 字节只含名称、中心、包围盒、父关系与来源，不内联多边形。几何采用 WGS84、1/10000 度整数差分，保留多岛、孔洞及闭合边界；一般层进一步简化至约 0.0025 度，香港采用 0.0005 度。它适合区域态势示意，不是测绘或门牌定位资料。

## 层级和实际覆盖

|范围|收录内容|已知边界|
|---|---|---|
|全球|258 个世界轮廓；177 个地区最细至 ADM2，23 个至 ADM1，3 个至 ADM3|55 个仅有轮廓；各国 ADM2 的行政含义不相同|
|中国大陆|31 省级；331 个有确证父代码的地级集合；2,850 个县、市、区等来源单位|县界来自2017年资料，不代表2026年的完整调整|
|日本|47 都道府县；1,742 市町村等地方单位|都道府县以下不伪造“市→县”中间层|
|台湾|22 县市；368 乡镇市区|县市是上级，乡镇市区是下级|
|香港|官方18区，中文及英文名称|2026-09-12版本；民政事务总署资料|
|澳门|来源中的4个地方单元|含澳门半岛、氹仔、路氹、路环方向的资料单元；不是完整7堂区数据|
|菲律宾、缅甸|保留已有上级层，补 ADM3 市/自治市、镇区|遵循各自行政体系|

县、郡、自治市、地方政府区、乡镇的法律层级不等同。七个浏览范围是导航入口；某地不存在对应层级或资料不足时，不生成一个虚构的省、市或县。部分小国一级行政区本身就是地方自治单位，目录将其标为对应的基层角色。

中国有一个需要特别避免的数据陷阱：geoBoundaries 的 `CHN-ADM2` 元数据明确写着 `County Level`，实际是另一套县界，不能当作地级市使用。本版排除了该重复层。`CHN-PREFECTURE` 以 GeoNames ADM3 行政父代码找到真实 ADM2 上级，只合并已核实归属的既有县界。所有这些集合都带有 `derived:true`、`partial:true`；未核实县不会按最近城市猜归属。直辖市县区直接归已知省级直辖市，不伪造另一套地级市。地方单位跨年份无法确定父级的107条记录保留国家父级，并列入 `unmatchedParents`。

1.11 的全部9,107个地理 ID 保留。旧中国来源中混入的10个香港区和4个澳门单元已修正行政归属；香港10个旧 ID 使用官方同名区的新几何，补齐8个原来缺少的区。保留 ID 不表示继续沿用错误的来源层级或旧父名。

大陆、分区沿用 Natural Earth 分区字段，并对跨洲地方单位按内部代表点区分俄罗斯东部、土耳其欧洲侧、哈萨克斯坦乌拉尔西侧、西奈及印尼巴布亚。俄罗斯东部使用“北亚”。这是地图导航分类，不改变行政边界、主权归属或当前控制者。跨越分区的单位以代表点确定导航位置。

## 来源、署名和许可

- [Natural Earth 1:10m 国家与地区](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-0-countries/)：公开领域。下载文件固定于仓库 `v5.1.2` 标签，包含小岛国和依赖地区；替代原先1:110m的177块世界底图。
- [geoBoundaries gbOpen API](https://www.geoboundaries.org/api.html)：380个使用中的源图层，各自的来源年份、原提供方、许可、固定 Git 下载地址和 SHA-256 均写入 `sources.json` 与索引。原始年份从2005年至2023年不等，不统一声称为2020年或当前界线。不同层分别遵守 ODbL、CC BY、CC BY-SA、政府开放条款或公开领域条件，数据许可不被项目代码许可替代。
- [GeoNames](https://download.geonames.org/export/dump/)：CC BY 4.0。中国、日本、台湾、韩国本地名称及有明确代码的中国父关系；只作确证配对，不用最近地名替代行政关系。
- [香港民政事务总署18区资料](https://data.gov.hk/en-data/dataset/hk-had-json1-hong-kong-administrative-boundaries/resource/c3810fd6-7b47-40f8-91bc-3e5bc9618cc8)：香港特别行政区政府、民政事务总署及 DATA.GOV.HK 保有相关知识产权，依[开放资料使用条款](https://data.gov.hk/en/terms-and-conditions)署名转载及改编。目录记录源文件哈希。

颜色与战争标记由游戏当下已知控制和冲突另行生成。不同来源对争议地区、行政边界和离岛的处理可能不同；行政资料不直接决定当前政权或前线。地图来源年份也不会覆盖 MOD 的开局人物、制度或玩家已完成的政治结果。

## 数据契约和重建

`src/data/world-geography-index.json` 保留简写字段：`id/n/c/r/l/z/b/p/a`；新增 `pi`（直接上级 ID）、`h`（country/province/city/county）、`ct`（大洲键）、`sr`（分区键）、`f`（几何层名）。来源或国别代码不可用于猜父级。`p` 是直接父级显示名；省级作用范围必须沿 `pi` 祖先链解析。

`public/maps/manifest.json` 提供 `layers`、`coverage`、`continents`、`subregions`、`unmatchedParents`、`downloadFailures`。每层记录文件名、实际数量、范围、字节数和 SHA-256。`<layer>-boundaries.json` 保持 `{version,scale,features:{id:polygons}}` 格式。旧 `asia-boundaries.json` 和误用的 `CHN-ADM2-boundaries.json` 已移出新包；旧部署历史资源的保留由发布流程负责。

重建：安装 Python 3 与 Shapely，执行 `python scripts/build-global-geography.py`。源文件和元数据缓存在 `.cache/geography`，不打包。已提交索引固定各 geoBoundaries 源 URL 的 Git 修订，已有缓存会复用；香港官方实时地址若更新，应核对新哈希和数据日期。删除源缓存后重建不是承诺所有实时供应方永远返回旧版本。

验证：`node --test tests/global-geography-data.test.mjs`，5项通过。覆盖所有分片的哈希、数量、几何 ID、整数坐标、闭环、索引完整性、父链无环和跨国错误、香港18区、郑州与新北父链、法国/巴西/澳大利亚/哈萨克斯坦不被同 ISO 的附属小岛重定向，以及保留缺失层级说明。

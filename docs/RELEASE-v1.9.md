# 1.9 人物关系、身份与语言

## 人物关系

人生页面的自身状况、世界局势旁新增人物关系入口。玩家位于画布中心，已接触的人通过带有关系状态的曲线相连；已认识人物之间的强联系另用虚线连接。圆内优先显示对应肖像；缺少来源的人物保留姓名首字，不把普通联系人替换成同一张通用脸。

支持自由拖动人物、平移、缩放、触屏双指、搜索、关系分类、聚焦人物和自动排列。每组桌面8人、手机6人，所有联系人都可搜索及分页访问。布局会避开头像与关系标签；总览可缩小全组，点击姓名可定位并放大。查看和排列图谱不消耗月份，不改变属性。

`relationshipGraph`保存稳定人物ID、名字、最近接触时间、关系种类与强度、关系说明。实际会面、合作、结盟、决裂等会更新图谱；新闻提名、传闻、假设和失败联系不自动增加认识的人。已有存档从旧关系记录及明确的开局背景迁移。模组人物之间的预设联系须双方都已出现，且满足已经公开的剧情前置；不展示未来人物与关系剧透。

图谱上限512个人物、4096条关系，每次叙事最多接收64条结构化关系变化。提示优先发送本次点名的人和最近联系人，最多96个人物、256条关系；该提示裁剪不删除保存的数据。

## 身份

新人生增加生理男性、生理女性、双性人、自行填写及暂不填写。性别、族裔、国籍或所属势力均可附加描述。族裔和势力允许自由设定，出生地与国籍分别保存；填写身份不会擅自改变所在地区、资金或属性。

这些字段保存于`profile.identity`并传给叙事服务，个人状态可查看。旧档案没有提供的信息保持空缺，不从名字、头像或出生地猜测。隐藏人物已有的出生、年龄与背景锁定规则保留。

## 语言与文风

首页及设置提供简体中文、繁体中文、English、日本語、한국어、火星文、水浒传文风。选择保存于本机与当前档案，读取档案采用其中语言。界面随选择更新，已写下的历史保留原文，下一段新叙事遵循所选语言或文风。

联网叙事将身份、当前语言、实际行动结果与关系一起发送，要求正文、选项及当期新闻使用所选语言。新闻翻译只匹配本月已存在的ID，不新增事件、重复影响或覆盖历史。姓名、自填身份、API地址与密钥不作界面翻译。

繁体使用本地OpenCC转换；火星文采用保留可读性的字形转换；水浒传文风允许古白话。英日韩本地续写根据实际工作、战斗、健康、迁居、联系和收支生成对应语言的短段落，原文可展开查看。本地新闻保留原报道，完整语义翻译由联网叙事提供；这不代表全部MOD文本已有人工多语种翻译。

355个固定选项的标签与说明都有英、日、韩译文，涵盖日常、重大事件、特殊人物、职业和续写动作。显示用选项保留对应的原动作语义，避免翻译后失去工作、迁居、参军等结算。英日韩及繁体的明确公共行动另校验地区和行动类别，防止工作或假设被模型扩写为战争。任意外文自由输入的时间旅行、年龄与职业解析仍有覆盖范围限制，不能把界面多语言支持等同于所有自然语言指令的完整解析。

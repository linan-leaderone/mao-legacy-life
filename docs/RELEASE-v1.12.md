# 1.12 全球行政地图与所在地

世界局势新增世界、所处大洲、所处大区、所处势力、所处省份、所处市、所处县七个视图。各层以人物实际所在地为基准，搜索和浏览别处不改变人物位置。头像标记随已完成的迁居行动更新，并随人生存档保存；只有省份信息时显示省级示意中心，不编造县名或街道坐标。

全球底图包含258个国家和地区轮廓、55,588个行政单位，203个国家和地区有地方行政层，55个暂时只有轮廓。不同国家的县、郡、市町村等对应当地真实层级；无对应层级或资料缺失时显示原因。香港18区已补齐；澳门现有来源仅含4个单位。331个中国地级集合由已核实的县级父代码组合，均标明部分覆盖。107条跨年份父链未能确认，保留国家上级。数据年份和覆盖详情见[地图数据说明](WORLD-MAP-v1.12.md)。

各国资料从MOD国家历史、角色、意识形态、国策、民族精神、州历史与本地化建立关联。161个地理实体映射MOD开局资料，港澳另有已核实基线；未来可释放TAG不会提前成为开局政权。地图展示已发生的政局与领土变化、战争及前线，资料缺失保持空缺。见[国家资料说明](COUNTRIES-v1.12.md)。

明确迁居保留县市位置；每月当地战争影响使用同一位置。当前国家的政治变化可保存、读档并在地图上展示，国外生活不再套用中国大陆机构。旧存档保留原有行政单位ID，并从已有所在地迁移位置记录。

地图几何拆分为384份文件，合计61.68MB。Android与Windows包含全部已收录数据；PWA按查看范围加载地方地图并校验缓存，首次查看未缓存区域需要联网。世界底图、地名索引与核心内容预缓存。体积检查上限为地图75MB、核心40MB、整体120MB，完整MOD审计库仍不进入运行包。

最终交付与检查结果见[验证记录](VERIFICATION.md)及[iPhone发布记录](IOS-VERIFICATION.md)。

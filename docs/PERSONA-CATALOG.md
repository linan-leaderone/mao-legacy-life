# 本地公开人物扩展库

`src/data/personas-catalog.json` 是供姓名精确匹配使用的离线扩展数据。它与逐人核实的 `personas.json`、`personas-curated-v15.json` 分开维护；人物名录不提供给开局姓名栏做下拉建议。运行时优先采用单独核实的档案，不能用批量条目覆盖它。

这份库是按公开资料覆盖范围和分区配额整理的快照，不是“全部知名人物”的完整名册。“有知名度”没有可据以验收的全球清单，公开数据库也会遗漏人物。不能因为一个名字没有命中便断言此人不存在或不知名。

## 数据来源与选择

数据来自 [Wikidata](https://www.wikidata.org/) 的公开结构化事实，经 [QLever 的 Wikidata 查询端点](https://qlever.dev/wikidata) 读取。实际端点为 `https://qlever.dev/api/wikidata`。Wikidata 结构化数据采用 [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing)。没有复制百科正文；每条记录保存 Wikidata QID 和对应条目 URL，并尽可能保存中文、日文百科条目链接。

筛选使用 `P31`（人）、`P569`（出生日期）、`P570`（死亡日期）、`P19`（出生地）、`P27`（国籍），以及跨语言维基站点条目数量。日期范围为1900年1月1日之后、2002年1月1日之前，并排除数据库记载在2020年1月1日前死亡的人。目标是2020年初已成年且在世的公开人物；缺失死亡日期不能单独证明仍然在世，未经逐人核实的档案仍可能有资料遗漏。毛泽东、邓小平的虚构特殊开局由另外的数据和逻辑实现。

澳门和香港按出生地及行政区域关系选取，台湾、日本及中国大陆按相应国籍字段选取。每组按跨语言维基站点条目数量排序后取上限：澳门600、香港1400、台湾2000、日本3000、大陆3000；先按澳门、香港、台湾、日本、大陆的顺序去重 QID。分组仅用于覆盖统计，不表示2020年的居住地或身份认同。库保留有可用中文或日文姓名的条目；只有英文姓名、缺失生日或公开出生地的条目不进入运行库。站点条目数包含维基百科以外的关联项目，只作为公开覆盖程度排序指标。

`P106`（职业）的已知开始日期晚于2020年的记录被过滤。若人物的 `P2031`（工作或创作活动开始时间）全部晚于2020年，整条记录被排除。没有读取当前职位 `P39`，没有把现今百科摘要拼成2020年履历。职业没有时间限定时只表示公开资料中的一般生涯领域，不能据此声称在2020年已有该项职位、成就或知名度。逐人核实的主要人物档案负责更精确的2020年身份。

## 字段和真实性边界

- `id`、`qid`：稳定标识；同一人以 QID 去重。姓名冲突应由运行时处理，不能仅因重名就任选一人。
- `name`、`aliases`：公开中文、繁体、日文和英文名称或别名。泛称如“主席”“天皇”“先生”被过滤。姓名或完整别名才可匹配。
- `birthDate`、`birthDatePrecision`：日、月、年三种精度。年精度只存 `YYYY`，月精度只存 `YYYY-MM`，不能把缺失月日的来源伪装成真实1月1日生日。对应 Wikidata [日期精度模型](https://www.wikidata.org/wiki/Help:Dates)。
- `birthPlace`、`birthPlaceQids`：公开出生地原始名称和来源实体。`place` 由出生地的行政区或国家关系推得，海外出生地点保留原名。`startLocation` 按主要公开关联地区近似，大陆人物有出生省份时沿用该省；没有证据支持更细活动层级时只保留大地区。日本人物即使出生于历史上的满洲，仍按日本近似开局活动地区；这项近似不能解释为2020年真实行踪或私人住址。
- `occupation`、`occupationQids`、`category`：生涯职业与便于覆盖审计的领域分类。分类为规则分组，有交叉职业时只计首个匹配领域，不能当成人物专业评价。
- `biography`：仅由公开出生年份、出生地构成；不补写成长、婚姻、犯罪、健康或2020年后的经历。
- `familyBackground`：未核实的家庭资料保持缺失，不猜亲属、资产和家庭社会地位。运行端数值是游戏估值，不是对真实人物智力、容貌、健康或财产的测评。
- `notes`：资料精度、2020职业和活动地限制；供生成约束与维护使用，不应直接插入沉浸正文。
- `sourceUrls`、`asOf`、`sitelinks`：来源、开局基准日期和选取时的跨语言百科条目数。`asOf` 指开局日期，**不表示抓取了2020年历史快照**；抓取时间在顶层 `generatedAt`。

## 重建与审计

本次生成9,058条记录，去重后的检索分组为大陆2,767、香港1,261、澳门98、台湾1,955、日本2,977。生日具备日精度8,528条、月精度164条、年精度366条。领域分类为政界与公共事务1,182、文化演艺与媒体2,319、科研教育与技术281、体育与竞技4,893、商业与经济105、其他278。维基站点覆盖的排序会偏向国际赛事选手，不能把这些比例视为各地区真实职业分布。

生成时核验35个运行地区对应的 Wikidata 实体标签，防止省市实体错配。显然不是地点的乐团记录不会作为出生地写入。其他百科事实的缺漏和争议仍需逐人资料订正，批量入库不能替代完整人物传记核实。

需要 Node.js 22 或更新版本。首次构建联网读取公开端点，所有查询正文与原始响应保存在 `.cache/persona-catalog/`；缓存不打入安卓或 Windows 包。游戏读取已经生成的 JSON，不在游玩时访问 Wikidata。

```powershell
node scripts/build-persona-catalog.mjs
node scripts/build-persona-catalog.mjs --offline
node scripts/build-persona-catalog.mjs --refresh
```

默认优先使用同一 SPARQL 正文哈希对应的缓存；`--offline` 要求全部缓存存在，`--refresh` 重新联网下载。可通过 `PERSONA_SPARQL_ENDPOINT` 指定兼容的端点。查询失败会终止，不会悄悄生成缺页名册。由于公开数据库持续更新，刷新后的条目、别名、来源数和分区排序可能改变。

完整覆盖统计保存在 `docs/PERSONA-CATALOG-STATS.json`，与运行库顶层 `counts` 一致。其地区数为上述检索分组，经去重和字段检查后的数量；开局省份分布另列 `places`。本库不涵盖所有未成年人、1900年及更早出生者、2020年前去世者、只有外语拉丁字母姓名者、缺少可用生日/出生地的名人，也不能保证覆盖仅在中文社群内知名、尚无合适公开结构化条目的人物。

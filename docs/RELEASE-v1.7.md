# 1.7.0 更新说明

Gemini入口默认使用`https://aiapi.shiwuyan.cn/v1beta`、Gemini原生协议与`gemini-4-argon`。升级仅识别原随包Google默认密钥并替换完整连接，用户自己的配置不被覆盖。Windows与Android包按授权包含新默认密钥；公开网页保留空密钥，访问无需注册。

每月生活接续已完成的行动与结果。主页面去掉独立的“上月回响”框，工资、奖金、装备消耗、伤势、感染和特殊身体成长参与下月叙事。错误年龄、虚构成长、感染自行消失及工作差错矛盾均有针对性校验。

新增四类工作小游戏：配送路线、工厂质检、柜台配单、办公校对。原有工资照常逐月结算，实际小游戏奖励单独入账。丧尸遭遇有街道、公园、工业区地形，支持移动、近战、射击、诱饵与出口撤离。当前装备与技能影响过程，非免疫人物被攻击会感染，感染可跨月持续；明确获得免疫或治愈的成功行动更新身体状态。

邓小平的水滴鱼立绘按提供的照片改绘，同时用于人物档案与捕食。已具参考素材的隐藏人物拥有单独立绘，缺少本人照片的人物按用户要求保留空缺；普通自建人物使用原创插画样式。具体覆盖见[立绘记录](PORTRAITS-v1.7.md)。可以导入已经制作好的成品肖像，图片仅在本机保存，不随JSON存档转移。

存档版本维持`timelineVersion: 5`，旧档自动补足遭遇状态，连接版本升至`providerRevision: 6`。iPhone仍采用可分享的PWA；无Apple签名IPA。最终交付与测试边界见[验证记录](VERIFICATION.md)。

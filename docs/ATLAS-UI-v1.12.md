# v1.12 地图分层与所在地

地图由 `src/world-map.js` 挂载在世界局势中。`src/atlas-navigation.js` 只计算地图视域与层级，不修改人生或地理归属；人物位置来自 `getPlayerPosition(state)`，不读取浏览器定位。

## 七个视图

- 世界图：全球底图。
- 所处大洲、所处大区：根据本人所在地的地理归类展开；大区为东亚、西欧等分区。
- 所处势力：读取当前控制权，合并该势力最细已知行政单位的范围，允许跨国管治。当地控制尚未确认时禁用。
- 所处省份、市、县：沿本人所在地的真实父级链查找。当地没有这一行政层，或人物位置尚不够具体时，按钮禁用并提供原因。

大洲与部分跨洋地理分区采用合理的大陆视窗，法国海外领地不会把欧洲视图拉成世界图。太平洋视图支持跨日界线绘制、点选和头像定位。跨洲行政区的分区来自地理索引中的当地归类，不改变其行政归属。

查找和点选远方地区仅供探索。七个按钮始终锚定本人，查找不会迁居；“回到本人”回到最细已知位置。行动提交后地图更新会重新读取位置、控制权和可用层级。旧层级不再适用时回到新的已知位置或世界图。

头像使用 `getPortrait(state)`，固定人物没有照片时仍不生成替代照片。标记放在已知行政区域的示意中心，界面明确说明精度；省份位置不会被说成省会或某个县。海洋、太空和未知所在地没有陆地位置时不放置推测标记。

## 边界加载

`public/maps/manifest.json` 记录各国层级、文件、覆盖情况和地理分区。世界底图先加载；局部边界按视野、缩放和明确选择的层级读取。一次常规视野最多选择六个国家层，加一个明确定位的层；世界总览不下载和解码全球县区。

解码缓存最多保留九层（含世界底图），离开视野的层从当前绘图集合移除。解码分批让出主线程；关闭地图会取消请求、移除输入与尺寸监听并清空实例引用。各国资料缺口在详情和覆盖目录中说明，不补造县界。

## 管治与资料

颜色、战事、前线和当前政体仍由 `deriveTerritorySituation` 推导。独立折叠的“2020 年开局资料”读取 `getCountryContext(...).baseline`，不会用已变更的领导覆盖原始开局资料。首都字段标为“首都所在地区”，因为原 MOD 指向州而非精确城市。各地行政层级与边界年份分别显示。

## 验证

`tests/atlas-navigation.test.mjs` 的 13 项测试验证七层定位、跨国迁居、省级位置不能推断市县、缺失行政层级、海洋位置、动态跨国势力范围、父链循环、按需加载上限、海外领地与日界线。浏览器使用独立测试页面检查河南省与金水区、巴黎与欧洲、在巴黎探索板桥后仍回到巴黎、海洋无陆地标记、390 像素组件布局。无横向溢出与控制台错误，不读写用户存档。临时测试页、服务和标签页已清理。

地图精度取决于来源的行政层级与边界年份，不代表实时测绘或实际 GPS 位置。

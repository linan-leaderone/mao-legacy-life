# 1.6.0 行为与内容说明

日期：2026-10-25（Asia/Taipei）。本轮重点是让明确行动真正改变人物和世界，同时让叙事、月度收支与保存记录保持一致。本文说明源码行为；安装包与公开网站是否更新，以 [VERIFICATION.md](VERIFICATION.md) 为准。

## 行动和时间

新人生提供“玩家完全不受限”“玩家影响力偏大”“玩家更受世界规则逻辑限制”三种选择。前两种承认肯定语气中已经完成的行动，补足过程、协作、成本与他人反应；第三种保留人物条件和成功概率。否定、条件句、传闻与仅仅设想不会自动变成事实。

明确穿越会改变日期与地区环境；原新闻保留为此前时代的记录。`month`记录日历位置，`turn`记录实际经历次数，因此到1976年不会出现负的经历次数，也不会把2020年的执政者、防疫和网络生活直接搬过去。返老还童后的年龄使用独立身体记录，随后每经历一个月增长一个月，不再恢复成开局年龄。历史人物的生日资料本身保持不变。

成为领导、帮助某方获胜、发动或结束战争会产生当前世界状态与独立新闻。主动干预可以改变原有发展方向；已发生的战争仍留在历史中。帮助别人掌权不会让本人自动变为国家领导人。永久和平阻止旧排程再次启动战争，后续明确主动发动战争可以继续改变世界。模型只能补充行动确实造成且本地未覆盖的公共事实，普通生活不能被随意升级为战争。

自然排程的大亚洲战争需要考虑当前形势：中华共和国成立后至少24个月、制宪会议后至少18个月，相关制度落实后另留12个月；当地仍在内战时继续等待。原先固定在2027年前后的事件因此可以推迟。台湾、日本自然内战仍须在台海停火之后；玩家自行引发内战属于主动改变时序。

## 生活、人物和社会反应

每月显示各项属性的实际净变化和原因，劳动收入与日常开支进入资金；持续就业按月领薪，辞职停止收入。道德、淫乱值、魅力加入原有多维属性，意识形态偏好独立保存。淫乱值不代表他人同意，未成年人物或未成年身体保持为0；成人关系仅限双方成年、自愿的非露骨描述。

当前政治人物有不同立场、目标与关系，通过独立的`npcPressure/npcActivity`影响尚未确定的局势，不与主角的公共影响混为一项。只展示已经公开的身份和关系，不提前泄露未来领袖或胜者。毛泽东逐渐苏醒和公开复活会带来支持、激动、质疑、担忧等不同反应，未公开阶段的知情范围有限。

邓小平仍在海中时，选择捕食可以打开大鱼吃小鱼小游戏，支持鼠标与手机触屏。吃到的鱼与成长结果随本月行动结算；取消不会推进月份或提交收获。已经化为人形、登陆或明确不捕食时不强行打开小游戏。

## 台湾与隐藏人物

新增18条台湾阶段报道，包括选后蓝绿政策争论、开战后的民众党和时代力量表态、基进党及左翼组织动员、青年军、全面动员、蔡赖交接、停火后的戒严争议、四方内战通行，以及Afterglow赴台、滞留、战时记录、临时演出和返日。区域报道合计104条，仍有16条独立民生新闻，配图沿用统一16:9画框。

新增隐藏人物美竹兰、丰川祥子、羽泽鸫、青叶摩卡、上原绯玛丽、宇田川巴，本地人物合并库共9,074份；姓名框不提供候选列表。另整理29份模组政治人物元数据，区分开局和经历后的思想、职位与关系。六名虚构人物缺少完整生日，年龄按模组与本作时序估算，未知家庭资料不编造；批量现实人物库不声称包含逐人的完整家庭与2020履历。详细来源及适配边界见 [LORE-v1.6.md](LORE-v1.6.md)。

## 连接和版本迁移

Gemini新默认转向用户指定的`https://aiapi.shiwuyan.cn/v1beta`，采用Gemini原生协议及`gemini-4-argon`。三个服务的密钥仍独立保存，可替换、清空或使用自定义模型；旧Google密钥保留原主机，不悄悄发送至转发站。公开PWA不内置个人默认密钥，用户授权的私有APK/Windows包保留默认配置。

源码1.6.0、Android versionCode 7、存档`timelineVersion: 5`、连接配置`providerRevision: 5`。旧存档迁移保留经历，JSON存档继续不包含API密钥。PWA保留免注册、免登录的公开链接及主屏幕安装方式；本轮没有原生iOS安装包。

# 1.14 控制区着色与开局亲属

地图删除开局档案尾注、边界来源与层级提示，以及“地图范围与资料”展开区。原始来源、许可和覆盖记录继续保留在 maps/sources.json、地图目录与项目文档中。

势力颜色按稳定身份确定，不随领导姓名变化。战时影响不再覆盖原有底色；前线县用实际拥有者颜色铺底、进攻方颜色画斜纹。图例展示当前视野的势力，详情显示进攻方。分裂国家在省级概览提前载入当地县级图层，仍按视窗和国家数量控制加载量。

MOD 映射无法确定控制方的市县，按人生种子、区划稳定标识、已有候选方与相邻控制情况模拟确定。结果在相同人生中固定，查看地图、推进月份或读档不会重新抽签；明确占领、开局选定势力和停火优先。模拟是架空人生中的状态，不会改写原始 MOD/地理证据资料。省级与国家级详情仍可汇总多个控制方。

普通新人物自动建立家庭或长期熟人关系，明确写出的家人优先。单亲、父母去世、孤儿及老年背景分别处理，家人姓名与头像随人生保存。真实隐藏人物只采用已有档案，未知姓名或生死不补写，缺照片保留空缺。明确无亲无故的人物可以从空关系图开始。旧档只迁移可证实关系，不突然补出随机在世父母。

少量人物的关系图初次打开会完整容纳头像与姓名，家属之间的连线避开中心人物；较大的关系网仍保留自由拖动、搜索和全览。

最终测试、原生包与公开网页发布状态分别见 VERIFICATION.md 和 IOS-VERIFICATION.md。

# 有日期的文化语境

`src/data/memes.json` 收录 25 条理解材料。它是针对明确行动的解释库，不是每月随机笑话池。`culturalContext(state,query)` 返回 `matches`、`anachronisms` 和 `guidance`：没有相关词、人物经历或主动提及时，不加入匹配；幼童不默认理解成人直播社群用语；跨地区使用须在主动讨论中国网络、翻译或特定人物等语境中成立。

`availableFrom/startMonth` 采用可靠资料已经确认出现的保守月份，并非声称最早首创日。只有年度榜单时取该年 12 月，因此一些实际在当年较早月份已出现的用语会稍晚开放，以避免倒置年份。人物主动说出未来才流行的表达时，可以作为个人新说法承接，但不得称为当时已经广泛流行。

# 1.13 开局政局、实际控制区与旗帜

国家开局资料重新关联国家历史、角色、州历史、初始化效果、on_action及ZZZ覆盖。共扫描4,162份来源，收录692个TAG与187个开局实体。朝鲜最终显示法西斯专政、主体思想与指令经济；不会再被原始history中的旧制度覆盖。地图资料展开后可查看经济制度、内阁成员、社会政策、政党与国家状况。条件无法确定的脚本保留审计记录，不假定未来事件已经发生。详见[国家资料](COUNTRIES-v1.13.md)。

开局所在地改为国家/实际管治势力、省份、城市、区划/县四级联动；缺失或不适用的层级跳过。国籍留空采用开局管治方对应国家，自行填写的国籍保留，迁居不自动改变国籍。人物位置精确保存到所选行政单位；隐藏人物仍采用其档案中的所在地，解除隐藏姓名后恢复普通选择。

开局控制关联2,566个地方单位，覆盖克里米亚、叙利亚、也门、阿富汗等分裂地区。现实县界与MOD战略地块不同；1,292项为多方或映射不确定，明确展示其状态。混合区划可选择某势力控制的部分开局，地图仍保留多方控制标记。局部占领不会把全国制度改写；已知势力的参战状态影响其控制区。详见[控制区说明](OPENING-CONTROL-v1.13.md)。

扫描6,257张MOD旗帜，收录2,375个标识，去重为1,696张PNG。开局、已发生的路线及当前控制方使用对应旗帜；玩家新建势力按地区和政治取向匹配并注明拟用。透明或缺失素材按明确优先顺序回退，不伪造对应关系。PWA旗帜与地方地图首次查看联网加载，校验后缓存。详见[旗帜来源](FLAGS-v1.13.md)。

兼容旧存档，既有国家资料、个人所在地与新的控制覆盖分别保存。最终构建、自动检查与公开部署结果见[验证记录](VERIFICATION.md)和[iPhone发布记录](IOS-VERIFICATION.md)。

# 1.15.0：收支、短期工作与生活后果

本版修正文字中的实际收支与资金数值不一致、临时工作被无限续期、确诊后缺少生活反应，以及政治人物越过当前职权发布安排的问题。

- 个人行动中已经收到、付出或明确设定余额的金额进入收支账目。模型补充的实际收支需有行动结果原句作为依据；工资、奖金和生活支出去重。报价、未来承诺、他人资产和项目预算不会直接变成个人资金。
- 一个月或一次性的工作在约定结束时结清，下一月恢复原身份或待业状态。明确长期就业才持续结算。旧档依据可读行动记录迁移就业期限，不推测补发历史金钱。
- 重大确诊保存为身体记录，区分待检查、确诊、治疗与恢复。刚得知病情时写个人反应和生活安排；已知情的关系人物参与后续，未告知者不会自动知道。身体记录可在自身状况查看，后续月份保留照护与情绪影响。
- 政治活动按当前政府、地方职权、党务、议事或民间活动表达。台湾报道不再配中国大陆立法会议画面。巴勒斯坦开局意识形态适配为社会民主主义，原 MOD 思想与来源保留在数据元信息。
- 新增隐藏人物弦卷心。精确填写姓名或明确引入后可使用她的家庭、乐队和人物关系资料；普通月份不会自主点名。生日、公开性格及关系的官方来源见 [人物资料](CHARACTER-KOKORO-v1.15.md)。

正文承接已经完成的行动，临时工作的结束、实际余款与身体状态进入后续上下文。不能用下一月日记再次结算前一月的钱，也不能让停下的工作自行恢复。

# DeepSeek 叙事接口

1.3.0 使用 `src/deepseek.js`，默认模型为 `deepseek-flash`。请求发送至 `https://api.deepseek.com/chat/completions`，使用 Bearer 身份验证、`response_format: json_object`、非思考模式、`temperature: 0.95`、最多2800输出token，不使用流式输出。可用模型通过 `/models` 查询。原有指定默认密钥保持不变，从构建默认值或已保存设置读取，不写入本文、剧情存档或日志。

`buildPrompt` 从未提交的 `nextContext` 副本构造目标月份。人物输入明确区分2020年初背景、行动月年龄、目标月年龄与当前身份。`person` 持续保存职业、状态、拘押、技能、项目、关系和事实；模型返回的 `personUpdate` 只补充与本次行动相关、已经发生的变化。已参军的人不能下月恢复成尚未入伍的学生，受拘押的人不能在没有相关行动的情况下自由外出。

上下文包含已发生世界史、当月独立新闻、地方制度、文化用语、行动结果、置顶事实、长期记忆和最近8个月记录。新闻携带 direct、indirect、remote、none 影响层次：远方灾害和政治措施不得自动套到本人所在地。台湾、日本、港澳、韩国使用当地机构与生活环境；大陆各省也有不同生活背景。

`getModContext` 每次最多提供6条当前分支已经公开的来源片段，不发送隐藏路线、未来事件或未完成国策。全量MOD审计索引不被运行端导入，也不整份传给模型；索引覆盖和实际268个宏观ID的映射边界见 `MOD-COVERAGE.md`。

默认“以我的叙述为先”对应 `actionOutcome.playerLed=true`。手动安排需写出实际实施、成果、必要协作和代价。本人明确写出的完成结果要求当月成立；研究、筹备或尝试才可保留为持续项目。`quality: costly` 表示办成所需的额外资源与后续问题，不能改写为梦境或直接否定。常规选择与“更多现实约束”按引擎给出的成败描写。世界影响仍受已知事实与作用范围约束，不能同时宣告互斥胜者。

每四个月随机有1–2个抉择月；其余月份必须返回空选项，抉择月份返回3–5项。正文不显示概率、规则与局外解释，新闻不占用个人行动。日期、属性、世界影响和排程仍由引擎掌管，返回的 `actionDelta` 固定清空。

`src/narrative.js` 提供简洁日常书面语要求，检查部分固定套话、碎句、可识别错龄、明确月份错误、两段大面积重复、已入伍身份回退和地区机构错用。行动结果与新月生活分属不同月份，新月新闻不得倒写为此前行动的原因。发生 `PROSE_REPAIR` 时最多自动重写一次，要求保留时间、行动结果与选项数量；重写不重新结算行动。该校验只能发现已覆盖的模式，不保证捕获所有事实或文风问题。

每个HTTP请求的超时为60秒。取消、HTTP错误、空内容、输出截断、JSON不完整或第二次校验仍失败均保留当前月份，可重试或使用一次本地叙事。自动重写涉及第二次请求，不代表单个请求超时后仍自动推进。

`scripts/check-deepseek.mjs` 读取本机私有设置检查真实叙事请求，不输出密钥。`DEEPSEEK-SAMPLES-v1.3.json` 保存了5个成功场景：台湾对大陆游行的地区隔离、日本对河南洪灾的地区隔离、河南本地灾情、年龄与入伍身份延续、离奇自由行动。它们证明这些实际请求返回成功，不代表全场景覆盖；最终测试、构建和实机边界由 `VERIFICATION.md` 记录。

官方依据：[模型名称与服务地址](https://api-docs.deepseek.com/quick_start/pricing/)、[Chat Completions 参数](https://api-docs.deepseek.com/api/create-chat-completion/)、[JSON Output 要求](https://api-docs.deepseek.com/guides/json_mode/)。

# 1.8 战斗规则

人数按玩家本人、同伴和敌方合计。10人以内使用回合制，11人起使用最长60秒的实时战斗。人类和丧尸遭遇适用相同分界；既有工作小游戏仍为45秒，海洋捕食保持原规则。

`battle-offer.js`从当前行动或眼前的危险识别交战、阵营与人数，支持中文和阿拉伯数字。新闻、参军、宣战、训练、假设、过去的战斗，以及明确已经结束或避开的遭遇不单独打开战斗。没有明确人数时，依场景给出固定种子的规模。每侧最多计入10,000人；大规模战斗将实际人数合并为至多48个敌方与24个友方标记，单位损失按所代表人数计算。

回合制等待时不会推进局面。选择目标不消耗行动；移动、有效进攻、射击、防御、包扎或撤离后，同伴和敌方行动。射程外或被掩体遮挡的射击不消耗弹药和回合。地形、距离、当前装备、技能、体力、护甲和免疫状态参与计算。

实时战斗显示当前区域和独立小地图；小地图显示己方、敌方、出口、障碍与视野。鼠标或触屏按住移动，松手停止；也支持方向键和WASD。暂停、切换后台或失焦会停止战斗，恢复后继续剩余时间。达到60秒、清除敌人、成功撤离或生命归零时结束。

`battle-game.js`负责状态与结果校验，`battle-view.js`只管理对话框、绘制和输入。`encounter-games.js`保留既有调用入口并分派新旧小游戏。结果包含最终健康、累计伤害、包扎恢复、弹药消耗、敌方与同伴损失、感染、耗时和结束原因。

完成后点击“继续这段经历”才将结果交给月份叙述。叙述成功并校验后，随本次行动提交一次。取消、Esc、关闭窗口、未完成或无效结果不改原存档、月份和装备；重试叙述复用已完成结果。健康按最终值相对开场值的净差结算，不能把包扎后的存活误判为死亡。人类交战不新增丧尸感染；既有感染仍保留。局部战斗胜负不直接替代国家战争的胜负。

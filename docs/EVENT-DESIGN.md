# 月度生活与新闻设计

1.3版继续将个人生活与世界报道分开。`src/data/life-events.json` 包含 **57条个人事件**，`src/data/lore.json` 提供 **37条分支中的268个不同宏观ID，其中86条为区域报道**，`src/data/news.json` 提供 **16条社会、产业和民生新闻**。月份、属性、行动、新闻影响与政治变化由 `src/engine.js` 统一结算，当前 `timelineVersion` 为4。

## 月份与个人安排

`isDecisionMonth` 以世界种子确定四个月分组，每组随机选出一个或两个抉择月，重试不会重新抽取。抉择月份本地内容与 DeepSeek 均提供三至五个选择；原有49条本地事件有五项，8条属性机会有三项；其他月份的 `options` 必须为空数组。所有月份仍可照常生活或手动输入安排。

提交安排后，`nextContext` 在副本上结算这个月的行动；明确迁居且成功时先更新所在地，保留当月产生的身份与项目变化，再累积个人行动的公共影响、调整尚未决定的发展方向，最后推进一个月并按新的所在地汇入报道与地方影响。DeepSeek 或本地叙事续写成功后，`advance` 才提交新状态。可识别的文风、错龄或局外说明错误会自动重写一次；网络失败、取消、格式不完整或重写仍不合格时，不提交月份与属性变化。读取新闻、查看状态、保存和读取界面本身不消耗时间。

个人内容记录具体的求学、工作、亲友、休息与生活事务。世界新闻不能替代个人经历，也不能要求读者必须就每则报道表态。正文用身处其中的人的语言表达，不写玩家、本局、路线锁定、触发节点、属性加成等说明；操作入口与设置中的必要说明不混入人生叙述。

## 初始属性与变化

普通开局的智力 `intelligence`、家境 `family`、体力 `fitness`、颜值 `appearance` 共分配20点，每项为0–10的整数且总和必须为20。初始状态按每点10转换到0–100。影响力 `influence` 由出身背景、家境、身份文本和年龄推导：高级公共身份具有较高基础值，未成年人的公共作用范围较小。公开人物档案使用固定叙事估值，不能把这些值称为真实测评或财产数据。

其他持续状态为健康、资金、人脉和压力。资金使用人民币等值，其他属性在0–100范围内。健康与体力分别表示当前身体状况和体能条件；家境与手头资金分别表示长期资源条件和可支配资金，不能混为同一指标。

`resolveAction` 使用与行动相关的能力、难度、智力、压力和年龄计算过程质量。默认 `narrative: player` 下，手动安排设为 `playerLed` 并实际推进：条件充足时顺利完成，条件不足时补足协作与资源，增加时间、资金或压力代价。大目标应写明当月已经完成的关键步骤，并保存在持续项目中，不能只写“以后再说”、幻想或直接否定。

常规选项以及 `narrative: balanced` 下的手动行动按条件和概率判断成败。相同种子、同月、同一安排的结算稳定，重试叙事不会重新抽取结果；受挫时仍可保留实际准备。影响力继续约束公共作用范围，自由叙述不能追溯抹除既成政治事实或同时制造互斥胜者。正文只写过程、结果与代价，不显示判定公式。

选项中的 `delta` 是选择后可能产生的变化，不是当月已经获得的奖励。数据通常使用非资金±1–5；引擎统一限制非资金变化幅度，资金另行设限。DeepSeek 返回的 `actionDelta` 不直接参与结算，避免模型和本地引擎重复增加属性。旧存档的 `knowledge` 迁移到智力。

## 个人事件覆盖与筛选

原有49条内容覆盖婴幼儿、学前、学龄、青少年、成人、老年以及中国台湾、日本地域生活。新增8条属性相关机会：

| 机会 | 最低年龄 | 属性条件 |
| --- | ---: | --- |
| 科研协作 | 16 | 智力≥70 |
| 奖学金 | 16 | 智力≥60 |
| 家庭经营 | 18 | 家境≥70 |
| 家庭照护资源 | 18 | 家境≥60 |
| 户外活动 | 16 | 体力≥65 |
| 团队体能活动 | 16 | 体力≥75 |
| 肖像与形象机会 | 16 | 颜值≥65 |
| 舞台机会 | 16 | 颜值≥75 |

`minAge`、`maxAge` 使用包含端点的整岁；`places` 限定所在地；`minStats`、`maxStats` 限定属性。引擎还根据事件类别与属性调整抽取权重，优先避开最近8个月出现的同一事件 ID。普通事件不自行宣布职业、政治身份、迁居、国家胜负或未出现的科技突破。

57条个人事件均有 `diary`，无选择月份使用这段已发生的生活记述，避免把等待回答的问题直接当作普通月记。抉择月份使用 `narrative` 与选项。

`occupationEvent` 在已知职业或拘押状态下优先提供相应生活，不机械抽回普通学生、无业者或自由出行场景。`person` 持续记录职业、状态、拘押、技能、项目、关系和事实；模型的 `personUpdate` 只补充当次行动已经带来的变化。开局背景永久保留为历史资料，不覆盖后来身份。

`narrative`、`diary` 与选项可用 `{location}`、`{name}`、`{goal}`，由引擎替换。孩子的生活围绕照护、学习与同伴，不能直接套用成人的就业与公共事务行为。迁居必须有明确意图且行动成功；地点识别支持主要城市与省份别名。所在地由引擎先确定，之后才结算下月当地新闻，不能单靠模型返回的地点悄悄搬家。

数据中保留的 `majorOptions` 是旧版响应素材，当前宏观新闻不再用它们占据个人选择栏。

## 地区与公开人物

普通开局保留大陆31个省级地区、港澳、台湾、日本共35个出生点。`src/regions.js` 依据所在地提供地方产业、生活压力、学校、机构与日常词汇，已发生政治变化会更新当地制度。大陆机构不套到台日港澳韩，地区历史不由未发生的现实后续代填。韩国环境可由公开人物或后续迁居进入。

`src/personas.js` 对完整姓名及已知别名做精确匹配，目前11份公开人物档案。匹配后固定公开出生信息、2020年初身份、家庭经历和叙事估值；人生意愿仍可填写。`currentAge` 按当前年月计算年龄，公开人物使用出生日期；提示分别给出行动月年龄与目标月年龄。不能用开局年龄或旧记忆替代当前年龄，也不必每个月重复报年龄。公开资料与估值边界见 `PERSONA-SOURCES.md`。

当地方言、网络用语只在相关且时间相符时进入文字。尚未流行的说法若由本人主动提出，可视作个人用语，不能声称已经全网流行。

## 新闻、图片与直接影响

宏观事件、`regionalStories` 与社会新闻均在进入月份时独立加入 `current.news`，并进入 `newsHistory`。同一月可以有多条：例如2021年7月的防控游行、郑州洪灾和大熊猫保护消息应并存。报道没有个人选项；展开或收起新闻不推进月份。非关键政策与生活细节可使用 `randomDelayMonths`，固定日期与前置次序保留。

新闻使用 `art` 指向 `public/art/*.webp`，统一在16:9画框展示。专用图片包括故宫、董志民、学校、限电、洪灾、银行、台湾内战、日本内战及左翼胜利图；其余主题复用已有插图。图片来源与转换记录见 `ART-SOURCES.md`。

`newsExposure` 按所在地、邻省关系、新闻地区、主题和当前月份计算 direct、indirect、remote、none 四类影响。`places` 限定直接影响地区，不限制其他地区读报；河南洪灾不会在日本或台湾造成当地洪水和扣款，大陆游行不会让当地居民遭受大陆基层机关管制。间接影响只写航运、订单或亲友联系等合理联系；远方与暂无影响的报道不能自动造成封控、停学、拘押或生活损失。

世界事件按实际暴露程度和家境计算经济缓冲。新闻影响只在首次进入该月时结算，查看、保存或读取不能重复施加。API提示中的新闻携带分层结果，个人正文不复述整份报道。

## 个人行动与历史约束

公共行动成功后，在 `worldPressure` 中积累本人对改革、稳定、经济、左翼力量、合作与紧张程度的影响。界面以“你的声音与回响”呈现这些记录；它们是个人行动的公共回响，不等于整个世界的总体趋势。作用随影响力扩大，从个人与地方事务逐渐延伸至国家和国际层面。较高影响力和连续行动可影响尚未落定的胡春华政策方向、经济承诺结果，以及陈文清时期台日内战的力量对比。

改变发展方向必须与已发生事实兼容：候选分支需要包含当前已发生的全部前置。不得改写已经执政的人、已经结束的战争或已经成立的制度。陈文清执政下，台湾四方内战与日本羽泽鸫／丰川祥子的内战始终保持绑定；台湾左胜对应日本左胜，其他台湾胜者对应日本右胜。具体内容和相对月份见 `LORE-SOURCES.md`。

原有中国2020–2028及后续时间线继续保留，新闻不应打乱台海固定日期、长征机的最早年份、2028年选举，或把毛远新第二次文革提前到大亚洲战争结束前。

所有台日内战，包括非陈文清的旧军政府／共和派发展，都要求台海战争已经结束。来源互斥与动态作用域未被完整执行时，不能把候选国策全部变成既成事实。

## 叙事与存档

`src/deepseek.js` 接收当前年龄、人物身份、属性、地方制度、已发生世界史、新月份报道、个人事件、行动结果、置顶事实、长期记忆和最近8个月记录。`getModContext` 最多提供6条当前已公开阶段的来源片段；未来分支名称、隐藏终局和原始审计条件不进入叙述。模型回应手动安排时服从引擎给出的实际结果与作用范围；普通月份不得强行补出选择，新闻不得写成个人已经采取的行动。

全量审计扫描685个脚本及1,164个本地化文件，索引21,218个定义；当前实际映射为268个宏观ID。`mod-corpus.json` 不进入运行包，也不整份发送模型。原作缺文、互斥国策、未建立的战争前置和动态条件仍有未接入内容，见 `MOD-COVERAGE.md`。实际 DeepSeek 样例见 `DEEPSEEK-SAMPLES-v1.3.json`；最终测试与打包状态由 `VERIFICATION.md` 记录。

三个可命名的本地保存位置与自动保存并存，均可在同一段人生中读取。文件导入导出用于跨平台迁移，密钥与连接设置不进入人生文件。“自身状况”显示当前属性和身份，“世界局势”按地区显示最新报道及历史，不展示未来结局。每条 `history.consequence` 保存对应本次行动的结果，避免错配上一月回响。旧版存档按新属性与新闻结构迁移，保留原 `history`；当前页重新整理为个人生活与独立新闻。

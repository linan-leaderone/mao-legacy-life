# v1.7 遭遇与工作小游戏

实现位于 `src/encounter-games.js`，界面样式位于 `src/encounter-games.css`。所有地图、敌人和工作内容均由本地代码生成，按存档种子、经历次数与本次行动生成稳定的 `offer.id`。模型不会生成或执行临时 JavaScript。一次最多45秒，暂停、切换到后台或窗口失焦会停止计时。

## 四类工作

| 工作类型 | 职业与操作 | 记录内容 |
| --- | --- | --- |
| 派送路线 | 配送、快递、外卖等；在街道上依次抵达8个收件点 | 已送达数量、碰到障碍的差错 |
| 工厂质检 | 工厂、流水线、维修、分拣等；检查裂纹、缺口和故障点，选择放行或拣出 | 正确检验数、误判数 |
| 柜台配单 | 餐厅、咖啡馆、服务员、店员等；按订单顺序准备饭团、热饮、甜点 | 完成订单数、配单差错 |
| 办公校对 | 会计、文员等其他工作；在4行原单与录入金额中找出不一致的一行 | 正确核对数、误判数 |

明确的本次工作种类优先于旧职业；“继续上班”沿用现有职业。这四类是职业对应的可玩模板，不表示每种职业都有独立模拟。明确工作行动可打开小游戏，普通安静月份不会仅因已有职业而强制打开。工作可以提前记录已经完成的部分。

智力、体力和已有相关技能决定工作熟练度；熟练度影响操作间隔与每项任务的奖金。当前体力影响派送移动速度。失误会抵扣本次任务奖金，奖金最低为0，上限为6000；普通月薪仍由原有就业收支结算。

## 丧尸遭遇

直接、当前的身边遭遇可以打开战斗；已发生的大陆丧尸扩散仅在大陆外出时按稳定种子抽样。远方新闻、电视报道、假设、否定、上月回顾和已经清除的遭遇不直接开战。海洋身体不进入这类陆地小游戏。

地图有街道、公园和工业区，使用建筑、树丛、货箱作为障碍。障碍阻挡移动与射线；泥地、碎石、散落货物会减慢人物与感染者。敌人数量从当前描述识别，限制在1–24名，并区分普通、快速和强壮类型。

- 鼠标或触屏在地图上指示移动方向；方向键与 WASD 也可移动。
- 挥击攻击近处目标；射击消耗弹药并自动瞄准射程内、未被障碍挡住的最近目标。
- 诱饵暂时转移附近感染者注意力；撤离需位于地图左侧的绿色出口。
- 按钮及数字键1–4执行挥击、射击、诱饵、撤离；空格暂停。

体力影响速度和近战伤害，训练经历影响攻击间隔与伤害；枪械、近战工具与护甲改变可用攻击和承伤。已存在的 `encounterState.equipment` 是当前装备的权威记录，空数组也有效。旧背景、旧经历以及家属装备不能恢复已经丢弃的武器或脱下的护甲。

战斗中“记录这次经历”在险情未结束时禁用，点击处理器也拦截提前提交。只有从出口撤离、清除全部敌人、45秒到时或健康归零后才能记录。结算层再次检查完成条件，不能仅把结果标记为 `completed: true` 就绕过。暂停和“退出，不记录”始终保留；取消会放弃整段尚未提交的经历，不推进月份。

## 感染与人物状态

未免疫者受到有效攻击就会感染；护甲完全挡住伤害时不产生感染。免疫只阻止感染，不能阻止实际伤势。既有感染不会因下一次没有受击而消失。感染持续到后续月份时，每月健康减3、压力加2；明确成功的治愈或获得免疫会清除感染记录。致命遭遇的健康归零在月度消息结算后仍保持，人生随之结束。

`encounterState` 保存 `infected`、`immune`、`infectionTurn`、`equipment`、`ammo` 和 `lastEncounterId`。没有枪时，随身子弹仍保留在库存中，不能射击，也不会因结束遭遇而消失。当前行动中明确取得装备、弹药、免疫或治愈时，先生成不改动原档的预览，再以相同条件进入正式结算。现有显式免疫状态优先于历史文本，否定或假设免疫不会提供保护。

## 提交、取消与资金契约

1. `actionEncounter` 根据当前状态和行动准备可重复计算的 offer；预览不改动时间、资金、历史和原装备。
2. `openEncounterGame` 返回结果或 `null`。关闭、Escape、退出及无法创建界面均返回 `null`，没有收益或伤势提交。
3. 结果放入 `action.meta.encounterGame`。引擎移除该字段后复算 offer，拒绝不同 offer、旧月份结果及不完整数值；合法数值按范围归一化。
4. `encounterResultEffect` 只返回属性增量、额外奖金、结果描述和状态增量。工作奖金作为单独账目加入既有月薪与开支，不能重复支付基础工资。
5. 只有叙事成功并确认提交后，月份与历史推进一次。重复预览得到同样结果；已提交结果不能在下一月再次领取。存档与读取保留感染、装备、弹药和对应的历史结果。

```powershell
node --test tests/encounter-games.test.mjs tests/encounter-engine-v17.test.mjs
```

覆盖职业映射、当前与远方遭遇区分、旧遭遇不重放、确定地图、障碍和地形、伤害与免疫、技能影响、结果限幅、暂停/取消、提前结束拦截、工资奖金只支付一次、弹药保存、装备丢弃与家属隔离、逐月感染、治愈、致命伤、预览重试与伪造结果拒绝。

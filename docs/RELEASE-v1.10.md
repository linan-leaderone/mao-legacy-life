# 1.10.0

普通人物与途中遇到的普通联系人现在使用程序化二次元像素头像。发型、配色、服装、配饰按人生种子和人物身份确定，存读档、迁居和时间旅行不重新随机。儿童、成人与老人有年龄层外观。9位固定人物及水滴鱼新增像素版，身份特征和原始参考保留；本机导入画像保留；没有参考图的固定隐藏人物继续留空。实现与覆盖见 [头像说明](AVATARS-v1.10.md)。

捕鱼、配送、柜台、质检、办公和战斗共用本人头像；战斗地图、本人名单与大规模战斗小地图都标记本人。头像只用于显示，取消小游戏不推进月份、不入账。小游戏无需联网生成图片。

Gemini 去掉重复发送的规则，压缩当月不适用的说明与重复字段。当前状态、长期事实、世界历史及存档仍然保留。实际对照输入量减少31.3%，请求体减少33.8%；最终有效样本耗时37.3秒与39.8秒，转发服务波动明显，本次不声称稳定加速。详细方法与样本见 [Gemini验证](GEMINI-SPEED-v1.10.md)。

公开源码导出使用明确目录清单，并扫描个人默认凭据及常见密钥格式。包含运行端、原生包装源码、测试、运行剧情和人物资料；不包含私人连接、签名材料、原生成品、缓存和完整MOD审计文件。源码默认不带任何API密钥，下载者可在首页填写自己的服务或离线游玩。

版本：1.10.0；Android versionCode：12。实际构建、部署与检查结果见 [验证记录](VERIFICATION.md)。

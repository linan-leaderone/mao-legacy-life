# 毛的遗产 · 人生档案

2020 年 1 月开始记录的一生。参考 [AI 人生重开手帐](https://re.maa-ai.com/) 的自由背景与叙事形式，依据本机 `../TFR-xinzuo-rebuild` 的本地化独立实现，不修改原 MOD。当前源码版本为 **1.10.0**。

## 从源码运行

需要 Node.js 22 或更新版本与 pnpm 10。公开源码不提供 API 密钥；可在首页填写自己的连接，或选择“不联网”。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

验证执行 `pnpm test`。公开网页/PWA 执行 `pnpm build:ios`，发布 `dist-ios/`；普通应用构建执行 `pnpm build`。Windows 与 Android 的封装方式见 [构建说明](docs/BUILD.md)。人物资料与运行剧情已随源码提供，正常游玩和构建不需要原 MOD；重新扫描 MOD 时才需要自行提供其目录。

`node scripts/export-public-source.mjs` 按明确目录清单导出公开源码并检查凭据。导出不含个人连接、签名材料、原生安装包、浏览器档案、查询缓存或完整 MOD 审计索引。API 密钥在各自设备上配置，不要提交到仓库。

## 开始与保存

- **iPhone / iPad（iOS 15.4+）**：在Safari打开[主屏幕安装版](https://mao-legacy-life-iphone.shady-shell-6921.chatgpt.site)，无需注册或登录，可直接分享链接；从分享菜单“添加到主屏幕”即可安装。安装后从主屏幕首次联网打开、等待“离线内容已就绪”，再设置API并开始人生。交付形式为PWA；完整说明见 [iPhone安装说明](docs/IOS.md)。
- **Windows 10/11 x64**：构建产物为 `release/MaoLegacyLife-Windows-x64.zip`。完整解压后运行其中的 `MaoLegacyLife.exe`，保留其他文件。
- **安卓 8.0 及以上**：构建产物为 `release/MaoLegacyLife-Android.apk`，由 Android System WebView 承载同一界面。
- 每次打开先进入首页，即使已有档案也可先选 **DeepSeek、Gemini 或自定义 API**，再继续人生、新建或读取。点击左上角品牌可返回首页；切换服务不改动进度，月度请求进行时暂时不能切换。
- 默认选择 **DeepSeek**，模型为 `deepseek-flash`；Gemini 默认模型为 `gemini-4-argon`。每项服务分别保存密钥与模型，输入后自动保存。支持测试连接、手填模型、导入连接配置和“不联网”；自定义服务可选 **OpenAI 兼容、Gemini 原生、Anthropic Messages** 三种协议。
- 连接配置使用 `providerRevision: 7` 和独立的 `providers` 对象。旧版单份配置迁移到对应服务，保留不联网偏好；清除密钥后会保留空值，重启不会重新填入默认密钥。Windows、Android 通过原生 HTTP 桥请求接口，避免 WebView 的跨域限制；普通浏览器仍受服务端 CORS 设置约束。连接细节见 `docs/API-PROVIDERS.md`。
- Windows、Android安装包按用户授权预填DeepSeek、Gemini两份默认密钥，由构建时的 `.private/settings.json` 注入；私有配置文件本身与签名私钥不打包。iPhone网页不含个人默认密钥，需在手机填写。人生存档不包含密钥，界面可分别替换或清除。叙事请求失败或取消时仍停留在原月，可重试或使用一次本地叙事。
- 进行中可通过“保存”“读取”使用 **三个可命名的保存位置**，也可导入、导出 JSON 文件。自动保存独立存在；读取另一份档案或开始新人生前保留上一份备份。Windows、安卓与iPhone共用存档格式。旧版存档保留既有人生历史，当前页按新版改为个人生活与独立新闻。Safari与主屏幕App的数据可能分开保存，应先安装再游玩，已有进度通过JSON转移。

上述路径是打包脚本的输出位置；实际包版本与验证记录见 `docs/BUILD.md`、`docs/VERIFICATION.md`。

## 一个月的生活

普通开局可选择中国大陆31个省级地区、香港、澳门、中国台湾或日本，共35个出生点，年龄为0–90岁。各地使用相应的家庭背景、学校、职业、办事机构和生活用语。将 **20点** 分配给智力、家境、体力与颜值，每项0–10点；开始后以0–100显示。影响力由家境、背景、身份与年龄推导，再随经历变化，不能直接分配。

输入已收录的公开人物姓名或完整别名，会发现对应的隐藏档案；姓名栏没有下拉提示。当前合并库含9,074份记录，其中55份主要/特殊档案及6份MOD虚构人物优先于9,058条批量公开资料，45条重合项已合并。新增毛远新、王沪宁、张又侠、李作成、李占良（良子）、幺幺（龚源浩）、陈吉宁、江泽民、胡锦涛、胡春华、陆昊、德仁、韩东方、韩德强、孔庆东等人物。精确匹配后固定出生资料、背景与初始估值，仍可填写人生意愿；同名无法确定时不随意锁定某人。

人物资料覆盖大陆、香港、澳门、台湾、日本的政治、文化、科研、体育与商业领域，并非全部知名人物。主要人物逐人整理2020年身份；批量档案只收录出生资料和一般职业领域，未知家庭情况保留未知，2020年具体所在地未逐人核实。只有年月或年份的生日以“约”显示年龄；幺幺依用户提供的故事设定约三岁开始，不预设后续悲剧。数值属于叙事估值，不是实际能力或财产测评。来源与覆盖边界见 `docs/PERSONA-SOURCES.md`、`docs/PERSONA-CURATED-v1.5.md`、`docs/PERSONA-CATALOG.md`。

填写“毛泽东”会在纪念堂水晶棺内苏醒，身体可随照护和自主行动恢复，明确提出复活时会落实到当月。填写“邓小平”会成为太平洋中的小鱼，逐步捕食、进化，也可指定海岸上岸或改变形态。这两段明确要求的幻想经历保存身体阶段、记忆与所在位置，读档后继续；普通人物仍沿用现实、政治与科幻基调。

大部分月份只记述个人生活。每四个月随机安排一至两个抉择月，本地内容与联网叙事均提供三至五个选择。任何月份都可点击“下个月”照常生活，或在底部写下自己的安排。提交后恰好推进一个月，先交代刚才的行动，再续写下个月的经历。

开局可选择完全不受限、影响力偏大或更受世界规则限制。前两种中，肯定描述为已完成的行动成为事实，允许穿越、改变年龄与直接干预世界；受限模式按条件与概率判断。否定、假设和他人传闻不当成已完成行动。当前年龄、职业、拘押状态、技能、项目和关系会持续保留，不在下个月恢复成开局身份。

新闻和国家大事独立呈现在当月报道中，同月可以有多则。展开报道、查看图片、查看自身状况和世界局势均不推进时间，也不占用个人行动。报道按所在地分为直接、间接、远方或暂无影响：河南洪灾不会让台湾或日本居民遭遇当地洪水，大陆政治措施也不会自动变成当地制度。新闻图片使用统一 **16:9画框**。

## 属性与世界变化

智力、家境、体力、颜值、影响力，以及健康、资金、人脉和压力都会随人生变化。属性影响个人事件的出现条件与权重，决定默认手动安排的质量和代价，也参与常规选择及“更多现实约束”下的成败。智力较高时可能遇到科研或奖学金机会；较好的家境、体力、颜值也各自带来不同经历。

公共行动留下的影响会逐渐积累。影响力较低时作用主要在身边，积累到较高水平后才可能形成地区、国家或国际影响。尚未形成结果的胡春华政策方向、经济承诺，以及陈文清时期台日内战的力量对比，可以受持续行动影响；已经发生的记录仍保留，直接成功干预可改变当前领导、胜负与停战安排，后续排程服从这些变化。

“自身状况”可查看当前属性、身份和经历；“世界局势”展示各地区最新报道与已经发生的新闻，不揭露尚未出现的结果；其中“你的行动带来的变化”表示个人行动带来的公共影响，不是整个世界的趋势指标。人生编年史保留个人经历、行动和当月新闻，支持检索；也可用“记住这件事”固定重要关系与事实。

## 剧情与来源

目前包含 **37条互斥分支**（中国24、台湾5、日本6、欧洲2），**286个不同宏观事件ID（其中104条区域报道）、16条社会新闻与57个个人生活事件**。来源见 `docs/LORE-SOURCES.md`、`docs/NEWS-SOURCES.md`；个人内容设计见 `docs/EVENT-DESIGN.md`，图片来源见 `docs/ART-SOURCES.md`。

只读审计扫描了685个脚本和1,164个本地化文件，索引21,218个定义及其静态关系。已映射的286个宏观ID才进入当前排程，部分生活后果是有说明的改编；并非全部 MOD 内容均可游玩。完整审计索引不进入网页构建、安装包或每次模型请求。逐 TAG 覆盖和未接入原因见 `docs/MOD-COVERAGE.md`。

既有中国时间线继续保留：2020年初疫情与民进党连任；2021年7月防控失序与游行、8月美国内战、10月台海战争。台海战争在2022年8、9、10月之一结束，惨胜、失败和经济崩溃分别衔接战后发展。张又侠政变、陈文清与胡春华的不同政治走向按真实前置与时间间隔展开。长征机不早于2024年；此前“1026年以后”按上下文理解为2026年以后，大亚洲战争不早于2027年，并在中华共和国成立24个月、制宪会议18个月和制度落实12个月之后安排；当前内战未结束时继续推迟，相关选举随实际政局调整。毛远新的第二次文革仍在大亚洲战争结束后发生，长征的左右制宪、秦晖三种方向与新革命保持互斥。

中国确定由陈文清执政时，台湾战后必然出现左翼联盟、民进党、国民党、基进党四方内战，日本同时经历羽泽鸫与丰川祥子的对抗。台湾左翼胜利与日本左翼胜利绑定；台湾其余三方胜利与日本右翼胜利绑定。新内容覆盖战后社会、制度讨论、经济重建与外交。原 MOD 缺少完整胜利文本的部分已在来源文档中注明改编依据。

故宫奔驰、董志民、郑州洪灾、村镇银行等新闻来自对应本地化条目；其他产业与民生报道保留来源和日期适配说明。它们与战争、政变共同构成架空历史背景，来源说明保留在文档中，日常叙述不插入规则或开发说明。

叙事以生活、政治与科幻为主。丧尸只属于相关生物灾害发展，不主动增加修仙或魔法。选中的叙事服务接收当前年龄和身份、当地制度、已发生世界史、当月新闻、行动结果及最多6条已公开 MOD 背景片段；它负责叙述，不直接更改月份、国家结果或属性。所有服务共用提示与结果校验。最近8个月的个人记录、最多80条长期记忆及置顶事实进入后续上下文，完整历史保存在本机。发现可识别的错龄、文风或局外说明问题时，自动重写一次；仍不合格则保留原月。

不联网时同样使用本地行动与世界结算，文字来自内置生活内容。57条个人事件都包含适用于无选择月份的独立月记，职业与拘押状态也有对应处理。明确迁居成功后，先变更所在地，再结算下月当地新闻的影响。实际 DeepSeek 场景记录见 `docs/DEEPSEEK-SAMPLES-v1.3.json`；最终验证与交付状态以 `docs/VERIFICATION.md` 为准。

## 开发

Node.js 22.12+，pnpm：

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm build:ios
node scripts/build-mod-corpus.mjs
node scripts/package-windows.mjs
pwsh -NoProfile -File scripts/package-android.ps1
```

`src/engine.js` 管理人物、月份、行动、世界排程与存档，当前 `timelineVersion` 为4；`src/regions.js` 管理当地环境与新闻影响，`src/personas.js` 管理公开人物开局，`src/mod-content.js` 限定已经公开的来源片段。`src/api-settings.js` 管理各服务配置与旧设置迁移，`src/api.js` 分发 DeepSeek、Gemini 和自定义协议请求，`src/api-transport.js` 统一原生桥与浏览器请求、超时和取消。密钥不要写入源码、文档、截图或日志。原生构建依赖、签名与工具路径见 `docs/BUILD.md`，API 协议与请求通道见 `docs/API-PROVIDERS.md`。MOD审计命令仅在来源文件夹可用时运行，常规构建不依赖它。
